# 네이버 블로그 AI 글쓰기 — 개인 개선판

이 저장소는 `makeit-edu/makeit-middle-kit-naver`를 개인 용도로 복사해 개선한 버전입니다. 원본 저장소는 바꾸지 않습니다.

이 버전은 네이버 정보성 글을 만들 때 다음을 강화합니다.

- 제목별 핵심 질문 5개와 공식 자료 사전 조사
- 확인되지 않은 금액·기간·조건을 추측하지 않는 원칙
- 정확히 5개의 `[소제목]` 구조, FAQ와 체크리스트
- 문장 중복·핵심 정보 누락·제목 불일치의 최종 품질 검수

## 설치

새 Codex 채팅에 아래 문장을 그대로 입력하세요.

```text
깃허브 2025kkongggg-lang/makeit-middle-kit-naver 저장소의 README를 읽고 거기 적힌 대로 설치해. 네이버 블로그 글쓰기만 사용하고 워드프레스·애드센스 기능은 사용하지 마.
```

Codex는 `앱/설치.mjs`를 실행해 이 저장소의 최신 실행 파일과 안내를 작업 폴더에 설정해야 합니다. 설치 뒤에는 새 채팅이 아니라 같은 채팅에서 아래처럼 요청합니다.

```text
네이버 글 써줘. 키워드: 국가장학금 신청방법
```

`글 만들어줘`처럼 네이버를 빼고 요청하면 다른 글쓰기 기능으로 인식될 수 있으므로, 항상 요청 첫머리에 `네이버`를 넣습니다.

## 실행 원칙

- 네이버에는 임시저장까지만 하며 발행은 직접 합니다.
- 공식 자료가 부족하거나 검색할 수 없는 경우에는 최신 사실처럼 단정하지 않습니다.
- API 키·비밀번호는 저장소에 올리지 않습니다.
