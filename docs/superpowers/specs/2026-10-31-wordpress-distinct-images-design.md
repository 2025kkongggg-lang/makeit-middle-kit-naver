# 워드프레스 승인글 이미지 분리 설계

## 목적

앞으로 생성하는 워드프레스 승인글에 서로 다른 이미지 두 장을 사용한다. 한 장은 대표이미지(썸네일)로만 사용하고, 다른 한 장은 본문 중간에만 넣는다.

## 선택한 방식

- 대표이미지와 본문 이미지를 각각 별도의 OpenAI 이미지 요청으로 생성한다.
- 대표이미지는 워드프레스 `featured_media`에만 연결하며 본문 HTML에는 삽입하지 않는다.
- 본문 이미지는 별도 파일명·프롬프트·대체문구·캡션으로 업로드하고 본문 중간에 한 번 삽입한다.
- 기존 임시글은 수정하지 않고 변경 이후 생성하는 글에만 적용한다.

## 실패 처리

- 대표이미지 생성 또는 업로드가 실패해도 본문 이미지 생성을 계속하고 글을 임시저장한다.
- 본문 이미지 생성 또는 업로드가 실패해도 대표이미지를 사용할 수 있으면 연결하고 글을 임시저장한다.
- 두 이미지가 모두 실패해도 본문이 정상이라면 이미지 없이 임시저장한다.
- 결과 기록에는 대표이미지와 본문 이미지의 성공 여부 및 누락 이유를 남긴다.

## 검증 기준

- 정상 흐름에서는 서로 다른 미디어 ID 두 개가 생긴다.
- 대표이미지 미디어 ID는 본문 HTML에 포함되지 않는다.
- 본문 이미지 미디어 ID는 본문 HTML에 정확히 한 번 포함된다.
- 이미지 실패는 글 생성 전체를 실패시키지 않는다.
- 비용 합계에는 실제로 성공한 이미지 생성 비용만 포함한다.

## 고려한 다른 방식

- 같은 이미지를 대표이미지와 본문에 재사용하는 방식은 사용자의 요구와 맞지 않아 제외했다.
- 외부 무료 이미지를 검색해 넣는 방식은 저작권과 출처 안정성 문제가 있어 제외했다.
