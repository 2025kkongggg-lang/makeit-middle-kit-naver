
## 네이버 글 — "네이버 글 써줘", "네이버", "블로그 글", "네이버 자동화"

2주차 기능이다. 위의 "말하는 법" 규칙(정해진 `>` 문장만, JSON·경로·코드 금지, 게이지·💰 줄만 그대로)을 똑같이 지킨다.
수강생에게 묻는 건 **키워드(또는 따라 쓸 네이버 글 주소)** 하나뿐이다. 주제·말투·분량·독자를 묻지 않는다. 글을 네가 직접 쓰지 않는다.

**사전 승인:** 네이버 프로그램 실행, OpenAI 호출, 크롬의 네이버 글쓰기 화면에 글·사진 넣기와 **임시저장**은 미리 승인돼 있다. 매번 묻지 않는다. **네이버 '발행' 버튼은 절대 누르지 않는다.** 사람이 한다. 네이버 화면의 다른 탭·다른 사이트는 건드리지 않는다.

**두 번째 길(셸)로는 네이버를 할 수 없다.** 크롬 조작은 `js` 도구 안에서만 된다. `js` 도구가 없으면 이렇게만 말한다:
> 네이버 글은 코덱스 앱의 크롬 연결이 필요해요. ChatGPT 앱을 완전히 껐다가 다시 켠 뒤 "네이버 글 써줘" 라고 다시 말해 주세요.

### ① 네이버 준비 코드 — `앱` 이 없으면 위 "준비 코드" 를 먼저 실행하고, 이어서 이것을 실행한다

```js
let 네이버 = await 앱.네이버.상태({ 작업폴더, 수강코드목록: 앱.수강코드목록 });
let agent = 네이버.키설정끝 && 네이버.크롬확장 ? await (await import(네이버.크롬확장)).setupBrowserRuntime() : null;
nodeRepl.write(JSON.stringify({ ...네이버, 크롬: agent ? "연결" : "없음" }, null, 1));
```

- `agent` 는 이 채팅에서 계속 재사용한다. `agent` 가 없다는 오류가 나면 이 코드를 다시 실행한다.
- `키설정끝: false` 면 (1주차를 안 했거나 새 폴더인 수강생) — **1주차와 똑같이 키 설정부터 한다.** 네이버 준비는 키 설정이 끝난 뒤에 한다.
  - `수강코드` 가 "됨" 이 아니면 위 "키 설정 ①" 그대로 한다:
    > 설치가 끝났어요. 이제 처음 한 번만 하는 키 설정입니다.
    > 먼저 강의 자료실 공지에 있는 **수강 코드**를 알려 주세요.
    받으면 `수강코드저장` → 위 "키 설정 ①" 의 두 번째 문장으로 **키설정.txt** 를 달라고 한다.
  - `수강코드` 는 "됨" 인데 `openai키` 가 "없음" 이면 "키 설정 ①" 의 두 번째 문장(키설정.txt 를 끌어다 놓아 달라)만 말한다.
  - 키설정.txt 를 받으면 위 "키 설정 ②" 의 `키설정적용` 을 실행하고 결과는 이렇게 말한다 (2주차에서는 이 규칙이 "키 설정 ②" 의 말보다 먼저다. 워드프레스가 안 돼도 OpenAI 키만 되면 네이버로 간다):
    - `전부됨: true` → 「수강 코드 확인 · OpenAI 키 확인 · 워드프레스 연결 확인. 키 설정이 끝났어요!」
    - `openai키` 가 "됨" 인데 사이트가 안 됐으면 → 「수강 코드 확인 · OpenAI 키 확인. 키 설정이 끝났어요!」 + 「워드프레스(승인글용)는 연결이 안 됐어요: «사이트 결과 한 줄». 네이버 글에는 필요 없어서 그대로 진행할게요. 승인글을 쓸 때 키설정.txt 를 고쳐 다시 넣어 주세요.」 (사이트 줄을 아예 안 적었으면 이 문장은 뺀다)
    - `openai키` 가 "됨" 이 아니면 → "키 설정 ②" 의 안 된 항목 문장대로 말하고 파일을 다시 기다린다.
    - `openai키` 가 "됨" 이면 곧바로 이 ① 을 다시 실행해 크롬을 연결하고 ② 로 간다. 제목 파일은 묻지 않는다.
- `크롬` 이 "없음" 이면 `할일` 을 「**«원인»**. «할일»」 로 말하고 기다린다.
- 준비가 다 됐으면 바로 ② 로 간다.

### ② 네이버 로그인 확인 — 묻지 말고 먼저 실행한다

```js
nodeRepl.write(JSON.stringify(await 앱.네이버.로그인확인({ agent })));
```

- `로그인: true` → ③ 으로.
- `로그인: false` →
  > 크롬을 켜고 네이버에 로그인해 주세요. (로그인 상태 유지를 체크해 두면 다음부터 안 물어봐요) 되면 "됐어요" 라고 해 주세요.
  "됐어요" 류의 답이 오면 ② 를 다시 실행한다. `할일` 이 로그인 말고 다른 것(크롬 연결 등)이면 그 「**«원인»**. «할일»」 을 말한다.

### ③ 키워드 받기

> 네이버 준비됐어요! 어떤 키워드로 글을 쓸까요? (예: 장수축하금 지원대상)
> 따라 쓰고 싶은 네이버 블로그 글 주소를 주셔도 돼요.

수강생이 이미 키워드를 말했으면 묻지 않고 바로 ④ 로 간다. 키워드를 여러 개 주면 하나씩 차례로 ④~⑤ 를 반복한다.

### ④ 글·사진 만들기 (1분 안팎)

먼저 한 줄: 「글과 사진을 만드는 중이에요. 1분쯤 걸려요.」

키워드:
```js
nodeRepl.write(JSON.stringify(await 앱.네이버.글만들기({ 작업폴더, 키워드: "«키워드»" }), null, 1));
```
글 주소(blog.naver.com/…):
```js
nodeRepl.write(JSON.stringify(await 앱.네이버.글만들기({ 작업폴더, 벤치마크URL: "«주소»" }), null, 1));
```

- `결과: "됨"` → 「글 완성: «제목» (사진 N장)」 한 줄과 `돈` 두 줄을 숫자 그대로 보여 주고, **묻지 말고** ⑤ 로 간다. `원고` 값을 ⑤ 에 쓴다.
  - `사진실패수` 가 1 이상이면 「사진 N장은 못 만들었어요. 글은 사진 없이 이어서 씁니다.」 한 줄을 덧붙인다.
- `결과: "실패"` → 「**«원인»**. «할일»」 하고 멈춘다. `할일.종류` 가 무엇이든 이 한 문장만 말한다 (문의·강사 이야기는 하지 않는다).
- `결과: "설정 필요"` → ① 의 OpenAI 키 단계로.

### ⑤ 네이버에 쓰기 (5~8분, 자동으로 나눠서)

먼저 한 줄: 「이제 네이버에 글을 씁니다. 크롬 창을 건드리지 말고 지켜봐 주세요. 5~8분 걸려요.」

```js
nodeRepl.write(JSON.stringify(await 앱.네이버.쓰기({ agent, 작업폴더, 원고: "«원고»" }), null, 1));
```

- `결과: "이어서"` → 수강생에게 묻지 말고 곧바로 같은 코드에 `시작블록: «시작블록»` 을 붙여 다시 실행한다. 또 "이어서" 가 나오면 또 한다. (말은 「계속 쓰는 중이에요…」 한 줄만)
  ```js
  nodeRepl.write(JSON.stringify(await 앱.네이버.쓰기({ agent, 작업폴더, 원고: "«원고»", 시작블록: «시작블록» }), null, 1));
  ```
- `결과: "됨"` →
  > 다 썼어요! 네이버에 **임시저장**해 뒀습니다.
  > 크롬 화면에서 글을 읽어 보시고, 괜찮으면 오른쪽 위 **'발행'** 을 직접 눌러 주세요. (창을 닫았다면 네이버 블로그 → 글쓰기 → 오른쪽 위 '저장' 옆 숫자에서 임시저장 글을 열 수 있어요)
  > 다음 글을 쓰려면 키워드만 말씀해 주세요.
  - `사진빠짐: true` 면 덧붙인다: 「사진만 빠졌어요. 크롬 주소창에 chrome://extensions 를 치고, ChatGPT 확장의 '세부정보' 에서 **'파일 URL에 대한 액세스 허용'** 을 켜면 다음 글부터 사진도 들어가요.」
  - `빠진블록` 이 있으면 덧붙인다: 「몇 군데(표·인용구 등)는 빠졌을 수 있어요. 발행 전에 한 번 확인해 주세요.」
  - `확인할곳` 이 있으면 (프로그램이 다 쓴 뒤 원고와 화면을 대조했는데, 한 번 다시 써도 남은 곳) 덧붙인다: 「발행 전에 이 부분만 한 번 확인해 주세요:」 + `확인할곳` 을 한 줄에 하나씩.
- `결과: "이어서"` 에 `다시쓰는중: true` 가 있으면 → 점검에서 잘못된 곳이 나와 같은 탭에서 처음부터 다시 쓰는 것이다. 말은 「잘못 들어간 곳이 있어 한 번 더 깔끔하게 다시 쓸게요.」 한 줄만 하고, 위와 똑같이 `시작블록: «시작블록»`(0) 으로 곧바로 다시 실행한다.
- `결과: "멈춤"` → 「**«원인»**. «할일»」 로 말하고 멈춘다. 수강생이 고치고 "다시", "다시 해줘", "네이버 글 써줘" 라고 하면 ② 부터 다시 한다 (글은 다시 만들지 않고 같은 `원고` 로 ⑤ 를 처음부터). `할일.종류` 가 무엇이든 이 한 문장만 말한다. 문의 채널·강사·"처방 목록" 같은 말은 하지 않는다.

- 어느 단계든 `결과: "이미 하는 중"` 이면 앞에서 시작한 작업이 아직 돌고 있다는 뜻이다. 같은 코드를 다시 실행하지 말고 앞 호출의 결과를 기다린다.

### 다음 글·이어서

- "또 써줘", 새 키워드 → ③ 부터. 로그인·키는 다시 묻지 않는다 (⑤ 에서 로그인이 풀려 멈추면 그때만 ②).
- 새 채팅에서 "네이버 글 써줘" 라고 하면 준비 코드 → ① 부터. `임시저장안된글` 이 있으면:
  > 지난번에 만들어 두고 네이버에 못 올린 글이 있어요: «제목». 이 글부터 올릴까요, 새 키워드로 쓸까요?
  "올려줘" 면 그 `원고` 로 ② → ⑤.

### 네이버 진단 — "네이버가 안 돼요", "네이버 진단"

```js
nodeRepl.write(JSON.stringify(await 앱.네이버.진단({ 작업폴더, agent: typeof agent === "undefined" ? null : agent, 수강코드목록: 앱.수강코드목록 }), null, 1));
```

> 수강 코드: «수강코드» · OpenAI 키: «openai키» · 크롬 확장: «크롬확장» · 네이버 로그인: «네이버로그인»
> 지금까지 쓴 네이버 글: «쓴글수»개
> 할 일: (아래)

그 뒤에 `할일` 을 한 줄씩 「**«원인»** → «할일»」. 비어 있으면 「지금은 이상 없어요.」. 문의·강사 이야기는 붙이지 않는다.
