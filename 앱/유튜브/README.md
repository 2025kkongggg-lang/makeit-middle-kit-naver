# 유튜브 정보형 감상문 (개발 브랜치)

기존 네이버 키트와 분리된 시범 기능입니다. **main과 기존 네이버 글쓰기/임시저장 흐름은 변경하지 않습니다.**

## 입력
- 유튜브 URL (watch, youtu.be, shorts, live, embed)
- 본인이 실제로 느낀 점 (필수)
- 적법하게 확보한 자막 또는 본인이 작성한 내용 메모 (필수)
- 영상 제목과 채널명 (선택)
- 기존 OpenAI API 키

## 결과
- 네이버 작성기와 호환되는 `원고.json` (제목 + 블록)
- `검토.json` (영상 주장 / 실제 사용자 감상 / AI 해설 / 확인 필요)
- 정확히 5개의 `[소제목]`
- 영상 출처 링크, 사진/캡처 생성 금지
- 자동 발행 금지. 별도 검토 후에만 기존 네이버 임시저장 단계로 연결할 것

## 예시 (Node.js)
```js
import {만들기} from "./앱/유튜브/정보형감상문.mjs";
const 결과 = await 만들기({
  url:"https://www.youtube.com/watch?v=XXXXXXXXXXX",
  감상:"실제 내가 느낀 점을 여기에 입력",
  자막:"사용 허락이 있거나 적법하게 확보한 자막/나의 영상 메모",
  영상제목:"확인한 영상 제목",
  채널명:"확인한 채널명",
  키:process.env.OPENAI_API_KEY,
  저장폴더:"./내_감상문"
});
console.log(결과.원고.제목, 결과.원고.블록.length);
```

## 보안/저작권 한계
- 유튜브 영상 다운로드·무단 캡처·자동 자막 추출을 하지 않습니다.
- 링크만으로 영상 내용을 분석하지 않습니다. 접근 권한을 확인할 수 없는 콘텐츠는 사용자가 메모를 제공해야 합니다.
- AI의 원문 유사도와 법적 인용 요건은 완전히 자동 판정할 수 없습니다. 반드시 사람이 검토해야 합니다.
- URL과 자막은 모델 호출 시 외부 API에 전달되므로 민감한 비공개 영상은 입력하지 마세요.
- 영상 내용과 AI 해설의 구분은 모델이 작성한 검토표이며, 독립적인 팩트체크가 아닙니다.
